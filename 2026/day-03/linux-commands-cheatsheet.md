# Day 03 – Linux Commands Practice

### 90-day Devops Learning plan

### Process management


 - `ps -aux` **Show all running processes**

 - `top` **Monitor CPU and memory usage in real time**

 - `pgrep` **Find process ID by process name**

 - `pstree` **Show all process in hierarchy**

 -  `kill` **Terminate a process using PID**

 -  `jobs` **Shows background jobs.**

---

### File system

 - `pwd` **Show current directory**

 - `ls -la` **List all files including hidden files**
 - `cd`  **Change directory**

 - `mkdir` **Create a directory**

 - `touch` **Create a file**

 - `cp` **Copy files and directories**

 - `grep` **Search text in files**

 - `cat` **Display file contents**

 - `chmod` **Change file permissions**

 - `chown` **Change file ownership**

---
### Networking troubleshooting

 - `ip addr` **Show IP addresses and network interfaces**

 - `ping` **Test network connectivity**

 - `curl` **Test websites and APIs**

 - `dig` **Check DNS records**

 - `nslookup` **Verify DNS resolution** 

 - `ss -tulnp` **View listening ports and active connections**

 - `netstat -tulnp` **Show network services and ports**

 - `traceroute` **Trace network path to a destination**

---

 ## What I Learned

Today, I practiced essential Linux commands used for process management, file system operations, and network troubleshooting. These commands are important for monitoring systems, managing files, checking connectivity, and troubleshooting issues in real-world Linux and DevOps environments.
